Основные функции C++

Главная Функции Циклы Примеры

1. cout

Используется для вывода информации на экран.

cout << "Hello World!";

2. cin

Используется для ввода данных пользователем.

int a;
cin >> a;

3. sqrt()

Находит квадратный корень числа.

sqrt(25);

4. pow()

Возводит число в степень.

pow(2, 3);
