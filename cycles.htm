Условия и циклы в C++

Главная Функции Циклы Примеры

Условие if

Позволяет программе проверять условия.

if (a > 0) {
cout << "Число положительное";
}

Цикл for

Повторяет действия несколько раз.

for (int i = 1; i <= 5; i++) {
cout << i;
}

Цикл while

Повторяет действия, пока условие верно.

while (a < 10) {
a++;
}
